代充卡网怎么搭？分享两种方式

最近有人问我要 API 上游，顺便把两种搭建思路分享一下。

① 上游 API + 卡网 + 第三方支付

对接上游的充值 API，用自己的卡网接单、收款。这种方式上手相对简单，但产品、价格和接口稳定性都会受上游限制。

② 充值协议 + 卡台 + 卡网 + 第三方支付

自己接充值协议，配合卡台完成充值，卡网负责接单和收款。需要自己处理协议适配和后续维护。卡台之前已经分享过，这次就不展开了。
