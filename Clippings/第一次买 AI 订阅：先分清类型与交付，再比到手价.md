## 第一步：先确定需要订阅还是 API

常用网页或 App，看 **账号订阅** ；让程序或插件调接口，才看 **API** 。第三方 API 中转不是官方会员，计费、额度和数据路径都不同。

先按使用方式分流，不跨类型比最低价

你主要在哪里使用 AI？

网页 / App

### 账号订阅

购买 ChatGPT、Claude、Gemini 等会员权益，再按交付方式区分直充、卡密、成品号与拼车。

程序调用

### API / 中转站

按模型与 token 用量计费。计费、额度和数据路径都不同于官方会员，不与账号订阅混比。

拿不准属于哪一类，先对照 [官方订阅、官方 API 与 API 中转站的区别](https://shuita.xyz/guide/api-relay-vs-subscription#%E5%AE%98%E6%96%B9%E8%AE%A2%E9%98%85-%E5%AE%98%E6%96%B9-api-%E4%B8%8E-api-%E4%B8%AD%E8%BD%AC%E7%AB%99%E6%9C%89%E4%BB%80%E4%B9%88%E5%8C%BA%E5%88%AB) ，两类商品不跨类比价。

## 第二步：看懂商品到底交付什么

同样写着「Plus 月付」，交付的东西可能完全不同。先看清账号归谁：

1. ### 直充 / 代充

	会员开通到你的账号，原有聊天记录和设置通常保留。

	核对：优先选自助卡密；代充先问清需要哪些凭证。
2. ### 卡密

	商家发兑换码，你自己在官网兑换，账号全程不离手。

	核对：兑换期限、适用地区与使用条件。
3. ### 成品号

	商家交付已开好会员的现成账号，绑定邮箱与找回权限往往不在你手里。

	核对：邮箱、找回方式与能否修改密码。
4. ### 拼车 / 车位

	多人共用同一账号或工作区，单价低，但对话可见且受管理员或车友影响。

	核对：隐私、额度与被移出后的处理规则。

更完整的对照见 [直充、成品号和拼车的区别](https://shuita.xyz/guide/chatgpt-plus-buying-options#%E7%9B%B4%E5%85%85-%E6%88%90%E5%93%81%E5%8F%B7%E5%92%8C%E6%8B%BC%E8%BD%A6%E6%9C%89%E4%BB%80%E4%B9%88%E5%8C%BA%E5%88%AB) 与 [卡网术语词典：交付方式](https://shuita.xyz/guide/ai-card-shop-glossary#%E4%BA%A4%E4%BB%98%E6%96%B9%E5%BC%8F-%E4%BD%A0%E6%9C%80%E5%90%8E%E6%8B%BF%E5%88%B0%E4%BB%80%E4%B9%88) 。报价页的标签也可以筛选同种交付形态。

## 第三步：只比较同规格的人民币到手价

交付形态一致，再比较期限、库存、到手价和质保。短效号与整月、共享与独享、首登与全程质保，对应不同的商品规格；地区标签只反映开通时的账号或支付渠道，不代表实际速度或稳定性。

商品页面 标价 人民币渠道 支付手续费 **本站统一比较 人民币到手价**

水獭默认按人民币付款的到手价排序，USDT 报价单独标出。遇到明显低价，先对照 [怎么判断一个价格合不合理](https://shuita.xyz/guide/official-vs-channel-prices#%E6%80%8E%E4%B9%88%E5%88%A4%E6%96%AD%E4%B8%80%E4%B8%AA%E4%BB%B7%E6%A0%BC%E5%90%88%E4%B8%8D%E5%90%88%E7%90%86) ，排查是不是缩短了期限或免除了质保。

## 第四步：下单核对，收货验收

「质保」二字不等于全程保障。按下面四步核对并验收：

1. **下单前核对**

	商品类型、有效期、交付方式、质保起算时间和赔付方式。
2. **保存交易凭证**

	商品页、质保说明、付款记录与订单号；标题含糊时以详情和店铺公告为准。
3. **收货立即验证**

	登录核对会员状态、有效期与约定权益；异常情况截图留证后联系店主。
4. **收回账号安全**

	代充完成后立即改密码并踢出其他设备；短信验证码与两步验证码始终自己保留。

可直接照着 [下单核对清单](https://shuita.xyz/guide/ai-subscription-buying-checklist#%E4%B8%8B%E5%8D%95%E5%89%8D-%E9%80%90%E9%A1%B9%E6%A0%B8%E5%AF%B9) 和 [账号安全底线](https://shuita.xyz/guide/ai-subscription-buying-checklist#%E4%BA%A4%E4%BB%98%E4%B8%8E%E8%B4%A6%E5%8F%B7%E5%AE%89%E5%85%A8%E7%9A%84%E5%BA%95%E7%BA%BF) 检查。
