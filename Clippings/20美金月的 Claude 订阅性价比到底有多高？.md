$20/月的 Claude 订阅性价比到底有多高？  
  
我用护照 KYC 的 Claude 账号终于倒下了。  
  
着急忙慌四处寻找替代品，包括一些号称满血 Opus/Falbe 中转站、第三方平台（比如 Devin, Factory 等）。  
  
但我比较好奇，到底这些平替能不能真的替代原版的 Claude 订阅。  
  
于是有了以下这些数据分析。  
  
TLDR：  
  
差别非常大，打 1 折的中转站和原版订阅比，也几乎是天价。  
  
首先看下自己账号的真实使用情况。  
  
根据 CodexBar 的使用量统计（已经计入了不同模型、缓存读写的实际价格）。  
  
我的 20 刀订阅的 Claude Pro 账号，过去30 天实际消耗（按照 API 价格）约为：$1239.  
  
也就是 1:60 的放大系数。  
  
1刀的费用，能用出 60 刀的 API 价值。  
  
中转站即便打 1 折（也就是按照 API 价格 -90%），那么也就是 1:10 的放大系数。  
  
1刀的费用，能用出 10 刀的 API 价值。  
  
中转站的价格，也等于你订阅的 6 倍。  
  
注意，我还没有每次都把所有额度用光（害怕封号，虽然最终结局一样）。  
  
按照 Gemini 的计算，如果是 $20 的 Claude Pro 订阅，你可以理解为一个 0.15 折的官方 API 中转站。  
  
如果是 Claude Max 订阅，大概是 0.2～0.3 折的样子。  
  
所以发现了吗？  
  
其实你真的想用 Opus 5.5 , Fable 5.2，而且想要不被封号，方法多的是。  
  
最简单粗暴的方式就是直接 OpenRouter 接入，满血、不降智。  
  
问题在于：  
  
原版 API 定价太贵了，普通人用不起。  
  
说白了大家就是想要便宜好用分量足、折扣极低的官方订阅。  
  
其实如果账算到这个份儿上，那么那些加价一倍卖的 Claude 订阅，似乎也不是不能接受。  
  
比如原价 $20，你花 $40 能用上，那也是 0.3 倍的折扣系数，比中转站的 1 折，还便宜 3 倍多呢。  
  
这多花的钱，就是国人税。
